# Vision

`soundsculpt` is a multi-device repo for experimental but usable Ableton tools.

## Principles

1. Build small, distinct devices instead of one giant everything-box.
2. Keep as much DSP as possible in text-friendly forms such as `genexpr`.
3. Use Max patches mainly for shell, controls, routing, transport sync, and packaging.
4. Treat every device as iterative: prototype first, refine tone later.
5. Reserve a later pass for analog-style character once the core effect is musically useful.

## Device categories we may grow into

- spatial devices
- modulation devices
- tone / colour devices
- rhythmic utilities
- hybrid weird boxes that do one thing unusually well
