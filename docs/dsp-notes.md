# DSP Notes

A scratchpad for reusable design ideas.

## Analog-style colour ideas to revisit

- soft saturation before and inside feedback paths
- frequency-dependent damping per repeat
- subtle stereo mismatch
- slow modulation / drift
- slightly imperfect diffusion
- bandwidth shaping and pre/de-emphasis style curves
- optional noise floor or texture, if musically justified

## Reverb directions

- plate-ish dark wash
- spring-adjacent resonant weirdness
- dubby BBD-style smear
- haunting unstable hardware-box character
